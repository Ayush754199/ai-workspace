# AI Workspace Mobile Branding

The existing `BrandLogo` widget is the current prototype identity. The production brand pass must provide original light/dark logo artwork, Android adaptive icon, iOS icon and splash assets under `assets/branding/` without reusing the Flutter logo or provider marks.

Current design tokens:

- Obsidian: `#090A0F`
- Onyx surface: `#13151E`
- Violet primary: `#7C3AED`
- Indigo secondary: `#6366F1`
- Cyan accent: `#06B6D4`
- System theme default: `ThemeMode.system`

Final icon and splash assets require a visual review on both light and dark device themes.
